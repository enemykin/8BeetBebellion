# Исследовательская сводка

## Игра

- Название: Linkin Park 8-Bit Rebellion!
- Оригинальная платформа: 32-битные версии iOS/iPhone OS.
- Известный bundle ID обычной версии: `com.alife.linkinpark`.
- Публично сохранившаяся версия, фигурировавшая в тестах: 1.4.5.
- Последняя известная официальная версия: 1.4.8.
- Существовало отдельное iPad Edition; его App Store ID отличался от обычной версии.

Все значения необходимо подтвердить по конкретному пользовательскому IPA, а не принимать на веру.

## Известный отчёт touchHLE

Публичный отчёт совместимости для версии 1.4.5 на touchHLE 0.2.3 фиксировал мгновенное завершение при динамическом запросе символа:

```text
_UIApplicationDidReceiveMemoryWarningNotification
```

Источники для ручной проверки:

- https://appdb.touchhle.org/apps/340
- https://github.com/touchHLE/touchHLE

## Наблюдение по актуальному исходному коду

В актуальной ветке touchHLE UIKit-константа `UIApplicationDidReceiveMemoryWarningNotification` уже присутствует и экспортируется как NSString. В то же время исторический текст ошибки формировался в пути `dlsym()` как запрос «не реализованной функции».

## Рабочая гипотеза

Игра может запрашивать через `dlsym()` адрес экспортируемой системной константы. Если текущий путь `dlsym()` разрешает только function exports, существующая constant export не будет найдена.

Проверить необходимо следующее:

1. Воспроизводится ли тот же сбой на закреплённой текущей ревизии.
2. Какая библиотека передаётся в `dlopen()` и какой handle используется в `dlsym()`.
3. Различает ли реализация адреса функций, классов и констант.
4. Как touchHLE материализует `HostConstant::NSString` в гостевой памяти.
5. Можно ли безопасно вернуть гостевой адрес уже созданной константы без нарушения кэширования и инвалидации CPU-кода.
6. Нужен ли общий API динамического линкера либо достаточно расширить существующий lookup.

## Критерии подтверждения первого исправления

Исправление считается подтверждённым только если:

- touchHLE успешно собирается;
- существующие тесты проходят;
- добавлен целевой тест или другое воспроизводимое доказательство;
- прежний сбой исчезает;
- журнал запуска показывает следующий этап либо новый конкретный блокер.
