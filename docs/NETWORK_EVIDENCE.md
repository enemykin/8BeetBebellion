# Сетевые признаки игры

Этот журнал фиксирует наблюдаемые сетевые вызовы и результаты запусков для будущего исследования мультиплеера. Адреса серверов, данные учётных записей и содержимое игровых ресурсов здесь не публикуются. Полные журналы остаются локально в игнорируемом Git каталоге `reports/`.

Затем вызывает `-[NSURL host]` и `-[NSURL port]`. | `reports/manual-run-2026-09-30_21-59-06-52490.log`, `reports/post-url-host-save-check.log` | Компоненты URL теперь разбираются в touchHLE; фактическое сетевое соединение на этих запусках не установлено. |
| 2026-09-30 | Та же последовательность | Игра вызывает `_CFStreamCreatePairWithSocketToHost` с указателями на читаемый и записываемый поток. | `reports/post-url-host-port-check.log` | В закреплённой ревизии touchHLE сокетные CFStream не реализованы. |

Пока подтверждена **попытка клиентского соединения**, а не работоспособность мультиплеера, доступность сервера или необходимость соединения для офлайн-кампании. Следующие проверки должны отдельно установить, где создаётся URL, какой код обрабатывает отсутствие соединения и доступны ли офлайн-сцены после этой ветви. Проверка не должна обходить аутентификацию, платежи или доступ к чужим аккаунтам.
